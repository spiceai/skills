# Hosts that may appear in a public commit or PR body.
#
# scrub.sh flags any URL whose host is not listed here. Matching is exact or
# by suffix, so `spiceai.org` also allows `docs.spiceai.org`. Hosts without a
# dot (placeholders like `<app-name>`) are skipped.
#
# The purpose of this check is to catch an internal hostname slipping into a
# public file — not to police third-party documentation links. When a run flags
# a legitimate new public host, append it here in the same PR; that addition is
# itself public-safe and gives reviewers a visible record of every external
# domain the skills point at.
