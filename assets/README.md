# Spice.ai plugin icon

`spiceai-logo.svg` is the unmodified 256 × 256 Spice.ai logo from the public
[Spice.ai documentation repository](https://github.com/spiceai/docs/blob/942ee39ed93d2f379168ca44c8406c6fcfdaba39/website/static/img/logo.svg).

Both OpenAI manifests use it for the listing logo and composer icon.
